EV Battery Monitoring SaaS

Transforming complex real-time battery data into clear, actionable insights for fleet operators.

Overview

Real-time health, at a glance.

Operators monitor hundreds of batteries at once, where a missed warning can be costly. The interface had to make critical status instantly legible and prioritise what needs attention right now.

I designed the monitoring dashboards, alerting system, and predictive views — built for fast scanning on large operations displays as well as desktop.

The work

Challenge & Solution

The Challenge

  • Complex, fast-moving real-time data
  • Critical alerts easily missed
  • Slow to diagnose battery issues
  • Information overload for operators

The Solution

  • Status-first dashboard with clear priority
  • Tiered, unmissable alerting system
  • Predictive insights for early action
  • Calm visual hierarchy for long shifts

Outcome

Faster response, fewer surprises.
